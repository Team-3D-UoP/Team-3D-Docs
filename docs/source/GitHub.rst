Version Control System
----------------------

Github was used for version control for this project.

Each member of the team had their own branch to work on, with the main branch being used to merge them together.
https://github.com/Team-3D-UoP/Team-3D-Rep/branches

Small commits that did not affect the entirety of the project were made to the main branch, whilst larger changes were made in seperate branches and merged when ready.

When the branch was ready to be merged, a pull request was created and reviewed by other members. Any necessary changes were made before the branch was merged into the main branch.

Progress checking
-----------------

Github's commit and pull request history was used to keep track of progress.

A checklist project was created https://github.com/orgs/Team-3D-UoP/projects/3,
where members could create issues that clearly showed where the team needed to focus their work. This also allowed us to easily track which sections of the project has been completed.
